# Before the Bell：测试与修复记录

这份记录依据项目现有规则测试、实现说明和美术素材记录整理。下表描述已处理的边界问题及当前回归检查点；没有历史失败日志的项目，不推断首次发现时间或故障发生频率。

| 检查的问题 | 处理与当前行为 | 回归验证 |
| --- | --- | --- |
| 后续波次的顾客若提前开始倒计时，会在出场前失去耐心；前一波未结束时也不应提前进场。 | 仅已到场订单消耗耐心；下一波等上一波清空后出现。顾客离开后释放占用设备，离店时间罚分只执行一次。 | `testNextWaveWaitsForPreviousWaveToClear`、`testHiddenCustomerDoesNotLosePatienceAndArrivesAfterService`、`testCustomerDeparturePenaltyHappensOnceAfterSigh`、`testTimeoutReleasesMachineAndAdmitsNextCustomerAfterSigh` |
| 错误设备、重复食材和设备正忙三种投放结果容易混淆，可能误扣时间或吞掉备餐区食材。 | 错误设备和重复投放各扣对应时间，食材仍留在备餐区；正确食材投向忙碌设备时返回“设备忙”，不计作失误，也不扣时间。 | `testWrongAndDuplicateDropsKeepIngredientAndDeductTime`、`testCorrectIngredientOnBusyMachineDoesNotCountAsWrongDrop` |

| 多订单同时操作时，设备完成的餐品可能归到当前选中的另一张订单。 | 成品保留启动设备时的订单归属；完成时切换到对应订单取餐，防止串单。 | `testFinishingAnotherOrdersMachineFocusesItsPickup`、`testSixthLevelTicketRequiresBagelAndCoffeeBeforeServing` |

## 画面与素材修复

- 顾客立绘曾有脸部、头发和衣物内部的透明洞；项目基于自身原创人物图补足透明区域，并在深色背景上检查。两张表情图的人物脸部 alpha 抽样达到 253/255 以上。
- 原料图集拆分时，相邻食材残影和游离像素可能进入同一槽位；项目改为独立食材图片，清理裁切边缘与散点，并逐张检查七种原料。
- 2–6 格原料槽开盖图与合盖图的外框、槽数曾不匹配；项目重绘相应档位，营业时只在对应槽口显示开盖区域，以避免外框叠影。

以上画面修复及原创素材来源记录于项目内部素材台账。作品集只展示最终游戏截图，不分发原始美术文件或第三方素材。
