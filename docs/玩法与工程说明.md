# Before the Bell：玩法与工程说明

## 一局如何进行

1. 营业开始前观察原料盒，记住本关食材所在的位置。
2. 顾客订单出现后取料，将材料放入备餐区，并按配方送到对应设备。
3. 根据设备提示在合适时机翻面、结束制作或取出成品。
4. 一个订单的餐品全部完成后打包交餐，获得分数与游戏金币。

前几关以单一订单建立操作习惯，随后加入并行订单、更多食材和设备。后期关卡会预告原料盒位置交换，并给玩家重新记忆的时间；预告阶段暂停营业及顾客计时。

## 核心设计

### 规则与表现分离

游戏规则集中在纯 Swift 模块。订单进度、原料取放、设备时机、成品品质、顾客耐心和奖励结算由规则状态决定；SwiftUI 根据状态显示场景并把点按、拖动等操作传回规则层。这让规则可以脱离图形界面单独测试，也让 iPhone、iPad 和 macOS 共享同一套玩法。

### 多尺寸场景

营业场景以 `1024 × 1536` 作为物体坐标基准，再依据实际窗口计算场景比例、可见区域和拖动坐标。设备图片框与可点击区域分开定义，避免视觉位置正确但交互热区偏移。较矮的屏幕会压缩备餐区域，宽屏可显示更多店内环境。

### 分层素材与状态

开店前使用完整静态主视觉；营业画面则组合背景、人物、设备、原料盒、成品及订单票等独立图层。设备外观和餐品状态随着玩法数据变化，图片不会代替规则判断。

### 本地进度

游戏金币、补给库存、装备选择与关卡最佳星级保存在设备本地。商店使用游戏内奖励币，不涉及应用内购买。

## 验证范围

项目包含纯 Swift 规则测试，覆盖订单、设备、原料和进度相关逻辑。此作品集展示现有实现思路和实际界面，不包含完整测试源码或测试日志，也不将模拟器验证等同于所有设备上的性能保证。
